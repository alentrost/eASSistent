# eASSistent

**eASSistent** je hitra in enostavna Android aplikacija za pregled urnika ter nadomeščanj iz sistema eAsistent.

## 📱 Funkcije

- 📅 **Pregled urnika**: Hitri 3-dnevni fokusni prikaz ali celotni tedenski pogled.
- ⏰ **Spremljanje v realnem času**: Označevanje trenutne šolske ure, odmora za malico ter preteklih in prihodnjih ur.
- 🔄 **Delovanje brez povezave**: Samodejno shranjevanje urnika za ogled tudi takrat, ko nimate internetne povezave.
- 🌙 **Temni način**: Podpora za svetlo in temno temo.
